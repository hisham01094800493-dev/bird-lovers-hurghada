# Bird listing image attributions

The marketplace cover-image mapping uses local copies of the following verified Wikimedia Commons photographs. The images are matched to listing titles by species name in `server/db.ts`.

| Listing type | Local asset | Source | License / attribution |
|---|---|---|---|
| Rainbow lorikeet | `/images/listing-lorikeet.jpg` | [Colorful Lorikeet (Unsplash)](https://commons.wikimedia.org/wiki/File:Colorful_Lorikeet_(Unsplash).jpg) | CC0 1.0; original photographer Daisy Kelly / idilux. |
| Green parakeet / budgie | `/images/listing-green-parakeet.jpg` | [Light Green Budgie](https://commons.wikimedia.org/wiki/File:Light_Green_Budgie.jpg) | CC BY 4.0; photographer VikiKalem. The source verifies the species and color, but not the claim that the bird is hand-tamed. |
| Blue-and-gold macaw | `/images/listing-blue-gold-macaw.jpg` | [Blue and Gold Macaw](https://commons.wikimedia.org/wiki/File:Blue_and_Gold_Macaw._(14345430528).jpg) | CC0 1.0; photograph by Bernard Spragg. NZ. |
| Cockatiel | `/images/listing-cockatiel.jpg` | [Cockatiel-Rico-001](https://commons.wikimedia.org/wiki/File:Cockatiel-Rico-001.jpg) | CC BY-SA 3.0; photographer Bensem51. |

These are **illustrative species-matched photos for the listing presentation**, not proof that the pictured bird is the seller's exact animal. Seller-uploaded photos should replace them when available, and the UI should avoid implying that a stock/species photo is the exact bird for sale.
